# Fashion Image Classification Using Convolutional Neural Networks (CNN) in Deep Learning

##  Project Overview

This project focuses on classifying fashion images using a Convolutional Neural Network (CNN), a deep learning technique for image recognition. The model is trained on the Fashion-MNIST dataset to identify clothing items across 10 different categories.

Implemented using Python and TensorFlow/Keras in Google Colab, the model achieved **93.14% test accuracy**.

##  Objective

To develop a deep learning model that automatically recognizes and classifies clothing images accurately using CNN.

##  Technologies Used
- Python
- Deep Learning
- CNN (Convolutional Neural Network)
- TensorFlow / Keras
- NumPy
- Matplotlib
- Fashion-MNIST Dataset
- Google Colab

##  Model Performance
- **Test Accuracy:** 93.14%
- **Task:** Multi-class image classification
- **Number of Classes:** 10
